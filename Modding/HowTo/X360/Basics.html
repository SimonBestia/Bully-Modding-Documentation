Basics: Xbox 360

First of all, getting in the files requires you to extract the contents of the .ISO.
Windows will let you double-click on it so you can access them all pretty easily, but if you edit any you'll need to repack them.

You'll need UltraISO to extract and rebuild the .ISO. See the PS2 Basics page for more details.

Edit files like you normally would on PC, though be wary of endianness differences.

Tools:

To extract World.IMG: use this quickBMS script.

Blender Plugin for .nif models: Blender Niftools Addon (or the modified one by VicLourenco).
